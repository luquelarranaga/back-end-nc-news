NC News
API Reference

A RESTful backend API for a news aggregation platform. Browse and filter articles, manage comments, explore topics, and look up users — all over JSON.

Base URL https://your-domain.com/api

Articles

GET /articles Retrieve all articles

Returns a list of all articles. Supports sorting, ordering, and filtering by topic via query parameters. Each article includes a total_comments count. The response does NOT include article bodies.

Query Parameters
sort_by = created_at | votes | title | author | topic order = asc | desc topic = string
Defaults
sort_by → created_at order → desc topic → null (all)
Example Response — 200 OK
{
  "articles": [
    {
      "article_id": 1,
      "title": "Living in the shadow of a great man",
      "author": "butter_bridge",
      "topic": "mitch",
      "created_at": "2020-07-09T21:11:00.000Z",
      "votes": 100,
      "article_img_url": "https://example.com/img.jpg",
      "total_comments": 11
    }
  ]
}
Note: Passing an invalid sort_by, order, or non-existent topic returns 400 Bad Request.
GET /articles/:article_id Retrieve a single article

Returns a single article by its numeric ID, including the full article body and a total_comments count.

Path Parameter
article_id — positive integer
Errors
400 — invalid id format 404 — article not found
Example Response — 200 OK
{
  "article": {
    "article_id": 1,
    "title": "Living in the shadow of a great man",
    "author": "butter_bridge",
    "body": "I find this existence challenging...",
    "topic": "mitch",
    "created_at": "2020-07-09T21:11:00.000Z",
    "votes": 100,
    "article_img_url": "https://example.com/img.jpg",
    "total_comments": 11
  }
}
PATCH /articles/:article_id Update article votes

Increments or decrements the vote count on an article. Pass a positive integer to upvote, or a negative integer to downvote. Returns the updated article object.

Request Body
inc_votes — integer (required)
Errors
400 — missing or extra body fields 400 — invalid article id 404 — article not found
Request Body
{ "inc_votes": 1 }
Example Response — 201 Created
{
  "article": {
    "article_id": 1,
    "votes": 101,
    ...
  }
}
Note: The body must contain only inc_votes. Any extra or missing fields return 400.
GET /articles/:article_id/comments Retrieve comments for an article

Returns all comments belonging to a specific article, sorted by created_at in descending order (most recent first).

Path Parameter
article_id — positive integer
Errors
400 — invalid id format 404 — article not found
Example Response — 200 OK
{
  "comments": [
    {
      "comment_id": 5,
      "article_id": 1,
      "author": "icellusedkars",
      "body": "I hate streaming noses",
      "votes": 0,
      "created_at": "2020-11-03T21:00:00.000Z"
    }
  ]
}
POST /articles/:article_id/comments Add a comment to an article

Posts a new comment to a specified article. The username must be an existing user. Returns the newly created comment object.

Request Body (required)
username — string body — string
Errors
400 — missing / extra body fields 400 — invalid article id 404 — article not found
Request Body
{
  "username": "butter_bridge",
  "body": "This is a great article!"
}
Example Response — 201 Created
{
  "comment": {
    "comment_id": 19,
    "article_id": 1,
    "author": "butter_bridge",
     "body": "This is a great article!",
    "votes": 0,
    "created_at": "2024-03-02T12:00:00.000Z"
  }
}
Note: The body must contain exactly username and body. Any extra or missing fields return 400.

Comments

DELETE /comments/:comment_id Delete a comment

Permanently deletes a comment by its ID. Returns a confirmation message on success.

Path Parameter
comment_id — positive integer
Errors
400 — invalid id format 404 — comment not found
Example Response — 200 OK
{ "msg": "comment deleted" }

Topics

GET /topics Retrieve all topics

Returns a list of all available topics. Topic slugs can be used as a topic filter when querying /articles.

Example Response — 200 OK
{
  "topics": [
    {
      "slug": "mitch",
      "description": "The man, the myth, the legend"
    },
    {
      "slug": "cats",
      "description": "Not dogs"
    }
  ]
}

Users

GET /users Retrieve all users

Returns an array of all registered users.

Example Response — 200 OK
{
  "users": [
    {
      "username": "butter_bridge",
      "name": "jonny",
      "avatar_url": "https://example.com/avatar.jpg"
    }
  ]
}
GET /users/:username Retrieve a single user

Returns a single user object matching the given username. Usernames must consist of word characters, digits, or underscores only.

Path Parameter
username — alphanumeric / underscores
Errors
400 — invalid username format 404 — username not found
Example Response — 200 OK
{
  "user": {
    "username": "butter_bridge",
    "name": "jonny",
    "avatar_url": "https://example.com/avatar.jpg"
  }
}
